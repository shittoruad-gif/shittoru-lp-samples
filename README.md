## 共通の仮設定（本番転用時に差し替え）
- 店舗名は全て架空（しっとる◯◯）。住所は株式会社しっとる実住所
- 電話 086-200-0000 はダミー・LINEボタンは `alert('仮リンクです')`
- 写真は全てUnsplashフリー素材（商用可・クレジット不要）。`images/` の同名ファイル置き換えで差し替え
- 料金・お客様の声はサンプル（各LPに注記あり）
- 地図はGoogleマップembed（第一セントラルビル）

## 運用
- GitHub Pages（repo: shittoruad-gif/shittoru-lp-samples, main直下）。pushで数十秒後に反映
- NG表現（根本改善/無料/解消/痩せる/断定表現）は全LPで回避済み（薬機法・景表法・広告審査対策）
